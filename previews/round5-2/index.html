2026 · garage assistant in Slack, web dashboard, Cloudflare

AI garage operations assistant and build tracker

Replaces a spreadsheet, a whiteboard, a retyped daily status doc, and a group text for vehicle builds and repairs.

Mechanics keep posting from their phones as they always have, and every build's record stays complete.

What it does

  • The build crew posts texts, photos, receipts, PDFs, and voice notes in Slack, and the garage assistant files each one to the right build. When the build is unclear or a post looks like a duplicate, it asks instead of guessing.
  • Several vision models read each receipt in parallel, and each field is decided by majority vote. Mismatched totals, duplicate invoices, and unusual prices go to a person.
  • Corrections work in plain words, such as "move the water pump to the other truck". Every change is logged and undoable, and invoiced records never move.
  • The garage leader gets a daily labor report and a phone-first board by build stage, with tasks, parts, receipts, and photos for each build.
  • A watchdog resends any post that stalls, then alerts a person. Failed deploys roll back on their own, and nightly backups get a monthly restore drill.
  • Designed to run on Cloudflare's $5-a-month Workers plan.

2026 · open source · github.com/redeemed2011/pi-toolbag

pi-toolbag: CTX long-horizon focus and LLM failover for coding agents

Coding agents stay on task for the long haul and keep working when a model provider fails.

  • CTX keeps a coding agent focused across context compactions without stopping useful exploration. It rebuilds context from typed records within a fixed token budget, with no extra model call.
  • Project rules are shared across sessions only after a person confirms them, so an agent's passing notes never become rules on their own.
  • Same-session failover switches models on quota, timeout, safety errors, and stalled streams, and never on auth errors or refusals. No user action is needed.
  • Usage-cap gates switch away before a model hits its limit and switch back once usage recovers.
how-it-works

Extensions for the Pi coding agent: CTX rebuilds working context after each compaction, and a shared failover library replays failed requests on the next model.

2026 · scheduled agent

AI job-search pipeline

Matching roles come straight from employers' own careers sites, each with a company card and scam and ghost-job checks.

Mail replies keep each role's status current, so nothing has to be tracked by hand.

  • On a test run of one metro area's employers, it kept 48 roles and dropped 326, each with its reason
  • Reads each employer's careers site broadly, then filters by fixed titles and rules. Covers Greenhouse, Lever, Ashby, Workday, Oracle, Phenom, Avature, and SmartRecruiters job feeds.
  • Sends only sites that block scripts to a browser agent running typesafe.ai's Jev, with spaced, backed-off requests.
  • Checks mail twice each weekday through a read-only mail agent, reading full threads so replies update each role's status.
  • Adds a company card for each employer with a kept role: financial health, recent layoffs, open-role trend, stock change, and recent headlines. Free sources only, and every figure carries its date and source.
  • Labels every role for scam risk and ghost-job risk with fixed rules, not a model's opinion. Hard flags, such as a fee up front or a request to run code, mark a likely scam. No label removes a role, and every dropped role shows its reason.
