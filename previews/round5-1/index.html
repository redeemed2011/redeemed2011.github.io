AI garage operations assistant and build tracker

2026 · garage assistant in Slack, web dashboard, Cloudflare

Replaces a spreadsheet, a whiteboard, a retyped daily status doc, and a group text for vehicle builds and repairs.

Mechanics keep posting from their phones as they always have, and every build's record stays complete.

  • Runs on Cloudflare's $5-a-month Workers plan

How it works

  1. The crew posts texts, photos, receipts, and voice notes in Slack
  2. The assistant files each post to the right build
  3. AI models read receipts and documents
  4. Records and files are saved
  5. Leaders see a phone-first build board

Details

  • When the build is unclear or a post looks like a duplicate, it asks instead of guessing.
  • Several vision models read each receipt in parallel, each field is decided by majority vote, and the arithmetic is checked. Mismatched totals, duplicate invoices, and unusual prices go to a person.
  • Duplicates are caught in any format: a photo, a PDF, and a typed note about the same receipt are compared on what they say.
  • Every write is logged and undoable, and nothing is hard-deleted. Corrections work in plain words, such as "move the water pump to the other truck", and invoiced records never move.
  • Labor hours are tracked without ever editing invoiced time, and the garage leader gets a daily labor report.
  • A watchdog resends any post that stalls, then alerts a person. Deploys roll back on failure, and nightly backups get a monthly restore drill.
  • Sign-in is Slack plus a passkey, with role-based permissions.
  • Cloudflare Workers

pi-toolbag: CTX long-horizon focus and LLM failover for coding agents

2026 · open source · github.com/redeemed2011/pi-toolbag

Coding agents that stay on task for the long haul and keep working when a model provider fails.

How it works

Extensions for the Pi coding agent. CTX rebuilds working context after each compaction, and a shared failover library replays a failed request on the next model.

Details

  • CTX keeps a coding agent focused across context compactions without stopping useful exploration. It rebuilds context from typed records within a fixed token budget, with no extra model call.
  • Project rules are shared across sessions only after a person confirms them, so an agent's passing notes never become rules on their own.
  • Failover switches models on quota, timeout, safety errors, and stalled streams, never on auth errors or refusals. No user action is needed.
  • Usage-cap gates switch away before a model hits its limit and switch back once usage recovers.
  • TypeScript
  • Pi coding agent
  • Vitest

AI job-search pipeline

2026 · scheduled agent

Matching roles come straight from employers' own careers sites, each checked for scam and ghost-job risk, and mail replies keep each role's status current.

  • Test run of one metro area: 48 roles kept, 326 dropped, each with its reason

How it works

  1. Employers' careers sites
  2. Title and rule filters
  3. Scam and ghost-job checks
  4. A page grouped by status

Details

  • Reads each employer's careers site broadly, then filters by fixed titles and rules. Covers Greenhouse, Lever, Ashby, Workday, Oracle, Phenom, Avature, and SmartRecruiters job feeds.
  • Sends only sites that block scripts to a browser agent, with spaced, backed-off requests.
  • Checks mail twice each weekday through a read-only mail agent, so replies update each role's status.
  • Adds a company card for each employer with a kept role, built from free public sources. Every figure carries its date and source.
  • Labels every role for scam risk and ghost-job risk with fixed rules, not a model's opinion. Hard flags, such as a fee up front or a request to run code, mark a likely scam. No label removes a role.
