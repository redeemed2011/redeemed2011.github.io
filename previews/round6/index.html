./garage-assistant · 2026 · Slack, web board, Cloudflare

AI garage operations assistant and build tracker

Replaces a spreadsheet, a whiteboard, a retyped daily status doc, and a group text for vehicle builds and repairs.

  • Runs on Cloudflare's $5-a-month Workers plan

What it does

  • The build crew posts texts, photos, receipts, PDFs, and voice notes in Slack, and the garage assistant files each one to the right build. When the build is unclear or a post looks like a duplicate, it asks instead of guessing.
  • Several vision models read each receipt in parallel, each field is decided by majority vote, and the arithmetic is checked.
  • Corrections work in plain words, such as "move the water pump to the other truck".
  • The garage leader gets a daily labor report and a phone-first board by build stage, with tasks, parts, receipts, and photos for each build.

Why it matters

  • Mechanics keep posting from their phones as they always have, and every build's record stays complete.
  • Mismatched totals, duplicate invoices, and unusual prices go to a person.
  • Every change is logged and undoable, nothing is hard-deleted, and invoiced records never move.
  • A watchdog resends any post that stalls, then alerts a person. Failed deploys roll back on their own, and nightly backups get a monthly restore drill.

./pi-toolbag · 2026 · open source · github.com/redeemed2011/pi-toolbag

pi-toolbag: CTX long-horizon focus and LLM failover for coding agents

Coding agents stay on task for the long haul and keep working when a model provider fails.

Extensions for the Pi coding agent.

What it does

  • CTX rebuilds a coding agent's working context after each compaction, from typed records within a fixed token budget, with no extra model call.
  • A shared failover library replays a failed request on the next model. It switches on quota, timeout, safety errors, and stalled streams, never on auth errors or refusals.
  • Usage-cap gates switch away before a model hits its limit and switch back once usage recovers.

Why it matters

  • The agent stays focused across compactions without stopping useful exploration.
  • No user action is needed when a model provider fails.
  • Project rules are shared across sessions only after a person confirms them, so an agent's passing notes never become rules on their own.
  • TypeScript
  • Pi coding agent
  • Vitest

./job-search · 2026 · scheduled agent

AI job-search pipeline

Matching roles come straight from employers' own careers sites, each checked for scam and ghost-job risk, and mail replies keep each role's status current.

  • Test run of one metro area: 48 roles kept, 326 dropped, each with its reason

What it does

  • Reads each employer's careers site broadly, then filters by fixed titles and rules. Covers Greenhouse, Lever, Ashby, Workday, Oracle, Phenom, Avature, and SmartRecruiters job feeds.
  • Sends only sites that block scripts to a browser agent, with spaced, backed-off requests.
  • Checks mail twice each weekday through a read-only mail agent, so replies update each role's status.
  • Adds a company card for each employer with a kept role, built from free public sources. Every figure carries its date and source.

Why it matters

  • Labels every role, and every email that claims to offer one, for scam and ghost-job risk with fixed rules, not a model's opinion.
  • Hard flags, such as a fee up front, a sender domain that doesn't match the company, or a request to run code, mark a likely scam.
  • No label removes a role, and every dropped role shows its reason.
  • Python
  • Careers-site job feeds
  • Read-only mail agent
  • Browser agent
  • SEC and WARN filings
  • Rule-based scam checks

~/models

Models I use and how

Each model has a specific job, and some jobs have a fallback.

  • Coding: xAI's Grok Build coding agent, run through my own sandboxed launcher, and the Pi coding agent with pi-toolbag, also running in my own sandbox. Pi's failover chain, in order: GLM-5.3 on Baseten, Grok through my SuperGrok subscription, Anthropic's Fable, Claude Opus, then Claude Sonnet.
  • Planning, review, browser control, and data ingest (personal work): Grok, Anthropic models, and OpenAI models plan and review. typesafe.ai's Jev runs the browser agent and makes data-ingest decisions.
  • Garage assistant receipt reading (Cloudflare Workers AI): Llama 4 Scout 17B, Mistral Small 3.1 24B, and Llama 3.2 11B Vision read each receipt in parallel, and each field is decided by majority vote.
  • Telling photos from documents (garage assistant): Llama 3.2 11B Vision plus ResNet-50 decide whether an upload is a document to read in full or a photo to describe.
  • Voice notes: Whisper large-v3-turbo transcribes, with Deepgram Nova-3 as the fallback.
  • At work: Astra/Terra, plus Fable, Opus, and Sonnet. I'm evaluating OpenAI's Decisions model for alerts, Kubernetes events, and log lines.
